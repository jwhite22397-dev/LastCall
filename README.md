# LAST CALL

A top-down action roguelite set in a nightclub. Survive from 2:00 AM until 6:00 AM.

## Run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

## Controls

- Desktop: WASD or arrow keys to move. Attacks are automatic. ESC pauses. F1 opens the debug panel during a run.
- Touch: virtual joystick on the left. Pause button in the corner. Upgrade cards are tap targets.

## Debug (F1)

Give XP, spawn enemies, elites, and bosses, toggle invincibility, advance the clock, add Clout, and prep a weapon evolution.
